# 텀프로젝트1(챗봇제작)

## 프로젝트 소개
- 이름: Chat_Base
- 주제: 야구 규칙을 알려주는 챗
- 주제 선정 이유: 새로 야구에 입문하게 된 사람들이 복잡한 야구 룰을 더 쉽게 알게 하기 위해 -> 야구에 입문했을 때 비슷해보여도 다 다른 상황에 복잡해했던 본인의 경험을 기반으로 생각해냄.
- 예상 사용자: 야구에 막 관심이 생긴 사람들

## 목표 구현 기능(이 중 2개 이상 해보기)
- [ ] 채팅을 통한 야구 룰 소개
- [ ] 로그인/회원가입 -> 응원팀 설정
- [ ] 가능하다면 현재 기록도 검색을 통해 쉽게 볼 수 있도록
- [ ] 복잡한 야구 용어 설명(기록과 관계된)

## 참고자료
- [KBO 공식 야구자료들(공식야구규칙, 규정 자료, 리그 규정 등)](https://www.koreabaseball.com/Kbo/Board/Ebook/EbookPublication.aspx)

## 실행 방법
```bash
    pip install -r requirements.txt
    uvicorn main:app --reload
```
  
## 현재 진행 상황: 50%
